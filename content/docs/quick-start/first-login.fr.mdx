Ouvrez d’abord le [site de production TianGong LCA](https://lca.tiangong.earth/), choisissez inscription ou connexion, puis suivez les étapes ci-dessous.

Bienvenue dans ce guide ! Voici les instructions pour créer rapidement un nouveau compte ou vous connecter à un compte existant.

## Inscription

Vous n'avez pas encore de compte ? Suivez ces étapes pour vous inscrire :

    1. Renseignez les informations d'inscription requises (adresse e-mail, mot de passe, etc.) comme indiqué.

    2. Cliquez sur le bouton **S'inscrire** pour finaliser la procédure.

![Capture d'écran de la page d'inscription](/assets/docs/0dcbf0ad/signup.png)

Une fois l'inscription réussie, vous pouvez immédiatement vous connecter avec l'adresse e-mail et le mot de passe fournis.

## Connexion

Si vous disposez déjà d'un compte, connectez-vous comme suit :

    1. Saisissez votre adresse e-mail et votre mot de passe.

    2. Cliquez sur le bouton **Connexion** pour accéder au système.

![Capture d'écran de la page de connexion](/assets/docs/fcaf0468/login.png)

Après votre première connexion, vous pouvez cliquer sur votre adresse e-mail en haut à droite. Un menu déroulant s'affiche avec les options **Profil du compte** et **Déconnexion**. Cliquez sur **[Profil du compte](/fr/docs/user-guide/account-profile/)** pour personnaliser vos paramètres.

La page d'accueil présente également l'entrée **Guide de développement des données**. À son ouverture, la **vidéo de démonstration des opérations** affiche d'abord **Chargement de la vidéo...**. Si la vidéo est temporairement indisponible, la page affiche **Échec du chargement de la vidéo** et propose **Recharger**. Le workflow de création de données reste décrit dans [Créer mes données](/fr/docs/user-guide/create-my-data/).

## Mot de passe oublié

Si vous avez oublié votre mot de passe, procédez comme suit pour le récupérer :

    1. Sur la page de connexion, cliquez sur le lien **Mot de passe oublié ?** pour ouvrir la page de récupération.

    2. Saisissez votre adresse e-mail enregistrée (celle associée à votre compte).

    3. Cliquez sur le bouton **Envoyer l'e-mail de vérification**.

![Capture d'écran de la récupération de mot de passe](/assets/docs/6f90cf4b/forgotpwd.png)

Le système enverra un e-mail de vérification à l'adresse indiquée. Suivez les instructions de l'e-mail pour réinitialiser votre mot de passe.
