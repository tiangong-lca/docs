本文帮助您从宏观角度理解 TianGong LCA 数据模块的定位、权限差异与常见用法，为后续的[数据新建](/zh/docs/user-guide/create-my-data/)和[数据审核](/zh/docs/user-guide/data-review/)做准备。

> 如果还没有账号，请先完成[首次登录](/zh/docs/quick-start/first-login/)与[操作演示](/zh/docs/quick-start/demonstrations/)。

## 核心概念词汇

- **模型（Model）**：用于描述产品或系统的过程网络，可作为过程引用。  
- **过程（Process）**：单元过程记录，包含输入输出流、建模信息和管理信息。  
- **流（Flow）**：物质、能源或经济流，需绑定单位组与流属性。  
- **单位组（Unit Group）**：对同类单位的集合，提供换算关系。  
- **来源（Source）/ 联系人（Contact）**：记录数据引用出处与责任人。  

这些概念在每个模块中都会出现，但权限和典型用途不同。

## 模块总览

| 模块 | 典型用户 | 主要用途 | 权限 | 常见操作 |
| --- | --- | --- | --- | --- |
| **开放数据** | 所有平台用户 | 浏览、引用官方审核的数据集 | 只读 | 搜索、筛选、复制、导出 |
| **商业数据** | 有商业数据需求的用户 | 查看商业数据元信息，与提供方联系 | 只读（元数据） | 浏览、复制、导出联系方式 |
| **我的数据** | 数据编写者/维护者 | 创建、编辑、导入与版本管理 | 读写；单位组与流属性为只读基础配置 | 新建、导入、编辑、贡献、提交审核；单位组与流属性可查看、搜索、导出 |
| **团队数据** | 团队成员 | 共享协作项目数据 | 只读（团队成员） | 搜索、引用、复制到个人空间 |

> **提示**：开放数据与商业数据均不支持直接修改。如需更改，请先复制到[我的数据](/zh/docs/user-guide/create-my-data/)中再编辑。
>
> 数据列表和搜索结果默认展示每个数据集 ID 的**最新可见版本**。如需回溯历史版本，请在数据行中使用
> **查看所有版本**。
>
> 如果您已经复制了某个数据集 ID，可以在联系人、来源、单位组、流属性、流、过程或模型列表中勾选
> **引用查找**，再输入完整数据集 UUID，用于查看当前数据空间中哪些记录引用了这个 ID。该结果同样受数据来源、团队和权限限制，并且最多展示前 50 条引用查找结果。

## 模块逐项说明

### 开放数据（Open Data）

- 收录平台审核通过的标准化生命周期数据。  
- 支持全量搜索、筛选与引用；列表结果按数据集展示最新已发布版本，适用于研究与分析场景。  
- 鼓励用户在数据成熟后提交审核，以便发布到该模块。

### 商业数据（Commercial Data）

- 展示商业化数据集的元信息（描述、范围、联系方式等）。  
- 不包含核心建模数据，获取完整数据需联系提供方。  
- 适合需要引入商业数据库、咨询服务的用户。

### 我的数据（My Data）

- 是数据编写与维护的主要工作区，可创建模型、过程、流、来源、联系人等对象。单位组和流属性属于基础配置，普通用户可在“我的数据”中查看、搜索、使用引用查找、查看所有版本并导出；新增、导入、复制、新增版本、编辑、删除和贡献通常由系统管理员处理，普通用户如需补充请联系管理员。
- 支持版本管理、导入/导出与团队贡献；普通列表优先显示最新可见版本，是提交审核的起始点。从“所有版本”创建新版本时，平台会保留同一数据集 ID 并自动生成下一版本号。  
- 详细操作请参见[数据新建](/zh/docs/user-guide/create-my-data/)与[数据使用](/zh/docs/user-guide/data-use/)。
- ⚠️ 如需新增单位组或流属性，请先评估对后续 LCIA 计算的影响，尽量复用平台提供的标准配置。

### 团队数据（Team Data）

- 向团队成员共享数据草稿与审核结果。  
- 允许复制到“我的数据”继续编辑，保障跨项目协同。  
- 数据维护仍需在“我的数据”中进行，团队空间主要负责展示与引用。

## 权限对照表

| 功能模块 | 查看完整数据 | 查看元数据 | 新建 | 编辑 | 删除 | 复制 |
| --- | --- | --- | --- | --- | --- | --- |
| 开放数据 | ✅ | | | | | ✅ |
| 商业数据 | | ✅ | | | | ✅ |
| 我的数据 | ✅ | ✅ | ✅* | ✅ | ✅ | ✅* |
| 团队数据 | ✅ | | | | | ✅ |

`*` 单位组与流属性在“我的数据”中对普通用户开放查看、搜索、引用查找、所有版本和导出；新增、导入、复制、新增版本、编辑、删除、贡献等维护入口仅系统管理员可用。若页面提示“需要新增或补充单位组？请联系管理员。”或“需要新增或补充流属性？请联系管理员。”，请先联系管理员完成基础配置维护。
