## 如何在 TianGong LCA 中构建模型？

1. 在“我的数据”中新建或选择现有过程，确保输入输出流配置完整。  
2. 打开“模型”模块，点击 `+` 创建模型，并通过右侧节点选择器将过程拖入画布。  
3. 连接输入输出流，设置基准过程与基准流量，完成后保存。详细操作可参考[数据新建](/zh/docs/user-guide/create-my-data/#新建模型model)。

## 保存模型时提示缺少引用过程怎么办？

如果保存时看到“模型缺少引用过程信息，请补全或重新绑定引用过程后重试。”，说明当前模型没有可用的
`referenceToReferenceProcess`。请回到模型画布，确认作为基准过程的节点仍然存在，然后重新设置参考过程
和基准流量后再保存。

## 保存或计算模型时提示输入流连接了多个供应方怎么办？

模型编辑器会检查画布中的显式连接。如果同一过程的同一输入流连接了多个不同的上游过程，
当前编辑器的本地计算会报告多供应方问题并停止计算。

请检查提示所指输入流的上游连接，根据实际供应关系纠正重复或错误的连接，使该输入流只连接
一个供应过程后再重试。如果实际场景需要多个供应者，应先确认相应的供应结构如何建模，
不要仅为通过校验而删除真实供应关系。

这项检查适用于编辑器中的显式连接。下文的隐式区域供应组合描述求解快照中的供应者选择，
不能据此认为编辑器已支持同一输入流的多个显式供应连接。

## 平台如何为产品输入选择供应者？

TianGong LCA **不提供独立的 ecoinvent 式 `market activity` 数据集**。当产品输入交换没有显式连接到唯一 provider 时，求解快照会使用**隐式区域供应组合**（默认规则 `split_by_process_volume`）：在通过数值准入与精确版本 Lifecycle Model 谱系门禁后，按“同 `model_id` 硬过滤 → 供应区域锚点（`exchange.location` 优先于过程位置）→ 首个非空地理层级 → 年供应量/年产量加权（缺失回退为固定权重 `1.0`）”分配权重。自动链接只接受 quantitative reference output；全为非参考候选时诊断会报告 `rejected_non_reference_only`。

隐式组合是计算期路由策略，不持久化为独立市场数据集，也不自动保证研究年份、技术或地理代表性。完整路由规则、诊断解读与何时应显式建模，请阅读[供应连接与市场机制](/zh/docs/database/supply-markets/)。

## 与其他 LCA 软件相比有哪些差异？

| 关注点 | TianGong LCA | 传统桌面软件（如 SimaPro、GaBi、openLCA 等） |
| --- | --- | --- |
| 数据管理 | 云端协作，支持团队贡献与审核流程 | 以本地项目为主，协作需额外同步 |
| 模型构建 | 基于过程库组合，可直接引用平台数据 | 多通过导入外部数据库或本地建库 |
| 数据结构 | 采用 TIDAS JSON 结构，支持开放接口与自动化集成 | 以专有数据库格式为主 |
| 版本控制 | 支持 Data check、自检与审核状态筛选 | 需依赖外部版本管理或手动记录 |

如需对照 TianGong LCA 与 ecoinvent、ILCD/EF、USLCI、BAFU、AGRIBALYSE 等背景数据库及格式转换边界，请阅读[跨库比较与格式互通](/zh/docs/database/comparison/)。

## 是否可以与其他软件互通？

- **导出 JSON**：用户可将过程或模型导出为标准 JSON，转换后导入其他平台。  
- **MCP 集成**：结合[天工 MCP](/zh/docs/integration/mcp-lca-remote/) 可在外部工具中调用 TianGong LCA 数据。
- **注意事项**：不同平台的单位、流属性命名可能存在差异，导出后建议进行字段映射或脚本清洗。

若需要更复杂的建模或与企业级系统对接，可联系平台支持团队获取集成方案。
