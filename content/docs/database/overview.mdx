> **30 秒看懂 TianGong LCA 数据库**
>
> - **数据底座开放且结构标准**：所有数据集遵循开源的 [TIDAS](https://tidas.tiangong.earth/) JSON 规范，与国际 ILCD/eILCD 结构高度兼容，可通过网页端、CLI、OpenAPI 与 [LCDN](https://lcdn.tiangong.earth/) 节点互通。

> - **实时覆盖以公开目录为准**：数据库持续增长，本文档不写死静态条数；最新数据量、地区与来源分布请直接查询[天工 LCA 公开数据目录](https://www.tiangong.earth/zh-CN/lca-database)。

## 二、数据库里的六类核心对象

TianGong LCA 按照 [TIDAS 核心对象关系](https://tidas.tiangong.earth/zh/docs/core-modules/data-relationships/)组织所有生命周期数据。为了直观理解，不妨想象您在研究“生产 1 吨甲醇”的环境足迹：

- **过程（Process）**相当于一张“生产配方与排放单”：记录生产 1 吨甲醇需要消耗多少天然气、电力和蒸汽，以及向大气、水体或土壤排放了多少污染物，同时附带地区、时间、工艺技术、数据来源与审核信息。过程分为两类：
  - **单元过程（Unit Process，常记作 `U(P)`）**：只记录这道工序自身的直接投入与直接排放。
  - **结果过程（Result Process，常记作 `R(P)`）**：把上游供应链一起算完后，汇总得到的“摇篮到大门”或特定边界下的完整清单与环境影响结果。
- **流（Flow）**相当于统一的“物料与排放字典”：为产品、中间原料、能源、废物以及自然界资源/排放赋予唯一身份（UUID）、精确版本与计量属性，确保不同过程提到的“二氧化碳（排放到空气）”或“工业用电”指向同一对象。TianGong 按用途把流分为四类：
  - **产品流（Product flow）**与**废物流（Waste flow）**：在人类生产体系（技术圈）内部流动，参与上下游供应连接。
  - **基本流（Elementary flow）**：直接从自然界开采的资源或直接排入环境的物质（生物圈），用于计算环境影响。
  - **其他流（Other flow）**：仅保留为说明性记录，不参与矩阵求解或影响评价。
- **生命周期模型（Lifecycle Model，常记作 `M(P)`）**相当于“供应链装配图”：把多个单元过程或结果过程放入画布，连起上下游供应关系并设定功能单位。在平台点击保存时，系统会执行计算，一并保存模型结构和生成的结果过程（详见[在平台中保存与复用模型结果](/zh/docs/overview/data-relationships/)）。
- **流属性（Flow Property）与单位组（Unit Group）**相当于“计量与换算标尺”：例如把“质量”关联到 `kg`、`t`、`g` 之间的换算系数，保证不同单位的投入产出能够正确汇总。平台提供标准基础配置，普通用户只需复用，无需自行重建。
- **来源（Source）与联系人（Contact）**相当于“文献档案与责任人名录”：记录论文、监测报告、问卷附件、数据编制者、审核者与版权所有者。
- **LCIA 评价方法（LCIA Methods）**相当于“环境影响换算表”：提供表征因子，把清单里的每一种基本流（如甲烷、二氧化硫、用水量）换算为气候变化、酸化、水资源消耗等环境影响指标。

| 对象类型 | 回答的核心问题 | 平台日常用途 |
| --- | --- | --- |
| **单元过程 `U(P)`** | 这道工序本身投入了什么、排放了什么 | 构建产品系统的基础积木，也是开放数据最常见的原始形态 |
| **生命周期模型 `M(P)`** | 多个过程是如何连接起来满足功能单位的 | 表达完整供应链结构、保存主产品与其他产品的计算结果 |
| **结果过程 `R(P)`** | 把上游背景系统算进去后，最终总清单与总影响是多少 | 在模型结果中查看，或在后续模型中直接作为上游背景复用（注：经正式发布流程归档的只读结果过程 `state_code = 120` 与常规输入过程严格隔离，详见[版本、许可与引用](/zh/docs/database/versions-citation/)） |
| **流 / 流属性 / 单位组** | 交换对象究竟是什么、按什么单位计量 | 支撑过程建模、跨过程连接和 LCIA 表征因子精确匹配 |
| **来源 / 联系人** | 数据从哪里来、由谁编制、归谁所有 | 支撑文献溯源、数据审核和合规引用 |

## 三、平台内置的 25 项 LCIA 评价方法

TianGong 平台与计算引擎使用一套经过统一审核的 **25 项静态 LCIA 方法包**（基于欧盟环境足迹 EF 指标框架与 IPCC、USEtox、AWARE 等主流科学模型），覆盖 12 大环境影响领域：

| 环境影响领域 | 包含的具体评价方法 | 指标单位 | 核心科学模型 / 来源 |
| --- | --- | --- | --- |
| **气候变化（4 项）** | 气候变化（总计）、生物源、化石源、土地利用与土地利用变化（LULUC） | `kg CO2 eq` | IPCC 100 年基准模型（GWP100） |
| **人类毒性——致癌（3 项）** | 致癌（总计）、致癌-无机物、致癌-有机物 | `CTUh` | USEtox |
| **人类毒性——非致癌（3 项）** | 非致癌（总计）、非致癌-无机物、非致癌-有机物 | `CTUh` | USEtox 2.1 |
| **淡水生态毒性（3 项）** | 淡水生态毒性（总计）、无机物、有机物 | `CTUe` | USEtox |
| **富营养化（3 项）** | 淡水富营养化；海水富营养化；陆地富营养化 | `kg P eq`；`kg N eq`；`mol N eq` | CARMEN / EUTREND；累积超标法（Accumulated Exceedance） |
| **资源消耗（2 项）** | 化石能源消耗；矿物与金属消耗 | `MJ`；`kg Sb eq` | 非生物资源消耗（ADP fossil / ADP ultimate reserve） |
| **水资源消耗（1 项）** | 水资源消耗 | `m3-world eq` | AWARE 100 |
| **土地利用（1 项）** | 土地利用 | 无量纲（`pt`） | 土壤质量指数（Soil quality index） |
| **酸化（1 项）** | 酸化 | `mol H+ eq` | 累积超标法（Accumulated Exceedance） |
| **臭氧消耗（1 项）** | 臭氧消耗 | `kg CFC11 eq` | WMO 臭氧消耗评估模型 |
| **电离辐射（1 项）** | 电离辐射——人类健康 | `kBq U235 eq` | 欧盟环境足迹配套电离辐射指标 |
| **光化学臭氧生成（1 项）** | 光化学烟雾——人类健康 | `kg NMVOC eq` | LOTOS-EUROS |
| **颗粒物（1 项）** | 颗粒物（EF-particulate Matter） | `disease incidence`（发病率） | 欧盟环境足迹配套颗粒物健康模型 |

使用这 25 项方法解读结果时，请特别记住三条计算约定（更多操作与排查见[LCIA 计算与结果查看](/zh/docs/user-guide/lcia/)）：

1. **当前为非区域化默认口径**：表征因子统一选用各方法的全球或无地区限定默认值，**不会**根据过程所在国家或省份自动切换区域化表征因子。若研究要求国家级或流域级区域化评价（如特定流域的水足迹），应在结果解释中说明或借助外部区域化因子。
2. **精确匹配流版本与方向**：系统按基本流的精确 UUID、版本号及输入/输出方向查找表征因子，不会仅凭流名称模糊匹配。
3. **缺因子绝不当成 0 影响**：如果某条基本流在目标方法中找不到对应表征因子，结果面板会将其明确标出为**覆盖不完整**并展示缺口明细，绝不会默默按“0 影响”掩盖。

## 四、四大工作数据空间与开放/商业边界

登录平台后，所有数据集按使用目的与权限划分到四个空间（详细操作和角色权限见[数据平台介绍](/zh/docs/user-guide/data/)与[权限与数据空间矩阵](/zh/docs/user-guide/permissions-and-data-scopes/)）：

| 数据空间 | 面向人群 | 典型内容 | 能做什么 / 不能做什么 |
| --- | --- | --- | --- |
| **开放数据（Open Data）** | 所有登录用户 | 通过平台[数据审核](/zh/docs/user-guide/data-review/)的公开标准数据集 | 只读；可全量搜索、查看、引用入模、导出 JSON，或复制到“我的数据”再编辑；是公开数值计算的合规数据来源 |
| **商业数据（Commercial Data）** | 需要引入第三方商业库的用户 | 商业数据库（如 HiQLCD 等）的描述性元信息 | 仅展示范围、简介与提供方联系方式，不包含完整投入产出清单；**不可直接引用到模型中**，如需完整数据与授权请联系对应提供方（见[商业数据库获取](/zh/docs/faq/commercial-database/)） |
| **我的数据（My Data）** | 数据编制者与维护者 | 个人新建、导入或复制出来的草稿、待审记录与自有版本 | 读写工作区（基础单位组与流属性由系统管理员统一维护）；在这里完成数据自检、贡献给团队或提交审核 |
| **团队数据（Team Data）** | 同一团队成员 | 团队成员贡献共享的项目数据与审核结果 | 对成员只读，避免多人同时覆盖同一份记录；修改时先复制到“我的数据”，改完再重新贡献 |

> 此外，平台为登录用户准备了只读的**精选示例数据**，方便新手熟悉结构与演练操作；示例数据不会混入开放数据目录统计，也不能由普通用户修改。

## 五、四步走：如何查找、核对并使用 TianGong 数据

无论您是做学术研究、产品碳足迹核算还是企业建模，都可以按以下四步一站式完成数据选用：

1. **查实时覆盖与找候选数据（无需登录）**
   打开[天工 LCA 公开数据目录](https://www.tiangong.earth/zh-CN/lca-database)，直接查看当前公开过程与流数据集的实时总数（按数据集 UUID 去重统计，同一数据集的多个历史版本不重复计数），并按关键词、地区或数据来源筛选候选记录。
2. **在版本详情页逐项核对适用性**
   打开目标记录的具体版本，重点核查五项信息：参考产品与功能单位、地理范围与参考年份、工艺技术与系统边界、原始文献来源与审核记录，以及该版本是否公开了**投入产出清单**和**环境影响结果**（这两项的公开状态在目录中分别标明）。
3. **核对许可条件并选择获取方式**
   在确认该版本的版权、许可类型与访问限制符合您的使用场景后（详见[版本、许可与引用](/zh/docs/database/versions-citation/)），根据工作流选择获取途径：
   - **在线建模与引用**：登录 [TianGong LCA 平台](https://lca.tiangong.earth/)，在开放数据中直接引用或复制到个人空间使用（见[数据使用](/zh/docs/user-guide/data-use/)）。
   - **批量导入导出**：使用网页端 [TIDAS ZIP 工作流](/zh/docs/user-guide/tidas-zip-workflows/) 或 [CLI 工具](/zh/docs/integration/cli/) 进行批量查询与数据包交换。
   - **ILCD 软件接入**：前往[天工生命周期数据网络（LCDN）](https://lcdn.tiangong.earth/)查看并获取 ILCD 格式分发包。
4. **计算后复核供应链接与因子覆盖**
   运行模型或 LCIA 计算后，务必检查求解快照的供应方选择与表征因子覆盖率，确认没有意外回退到不具代表性的全球数据，也没有关键基本流遗漏表征因子。

## 六、数据质量、审核与不确定性：目前提供什么、边界在哪

很多用户会问：“TianGong 里的数据质量评分怎么看？支持自动跑蒙特卡洛不确定性分析吗？”这里给出清晰、不夸大的回答：

### 当前已提供的结构化证据

- **七项 TIDAS 数据质量指标（DQI）**：每份过程审核记录支持按国际 ILCD/TIDAS 规范记录 **技术代表性、时间代表性、地理代表性、完整性、精确度、方法适宜性与一致性、综合质量**七个维度，采用五级定性评级（`Very good` → `Good` → `Fair` → `Poor` → `Very poor`，外加 `Not evaluated / unknown` 与 `Not applicable`）。
- **多维度审核与合规声明**：TIDAS 记录了审核独立性级别（内部审核、外部独立审核、认可第三方审核、独立专家组等）、具体核查方法（质量平衡、能量平衡、元素平衡、交叉核对、ISO 14040/14044 合规检查等），以及平台内的多角色[数据审核](/zh/docs/user-guide/data-review/)流程。
- **交换级不确定性记录字段**：TIDAS Schema 支持在投入产出交换与 LCIA 结果中记录分布类型（`log-normal`、`normal`、`triangular`、`uniform`、`undefined`）及 95% 相对标准差（`relativeStandardDeviation95In`）。
- **计算透明度诊断**：求解结果明确暴露表征因子覆盖缺口、供应方年产量缺失回退次数与地理匹配层级。

### 当前的明确边界

- **可见或可算不等于代表性达标**：数据集进入开放目录、或模型自动求解成功，均**不自动证明**其满足您具体研究的年份、工艺路线或地区代表性。
- **尚未对全库统一提供自动蒙特卡洛传播**：虽然 TIDAS 结构可以存储不确定性参数，但不同来源数据的填写完整度存在差异，平台当前也不默认对所有计算自动输出蒙特卡洛（Monte Carlo）概率分布区间。

若您需要系统掌握背景数据适用性审查、质量评分（DQR / pedigree 矩阵）如何转化为不确定性以及概率分析边界，请延伸阅读天工 LCA 知识库的[数据适用性](https://prism.tiangong.earth/zh/docs/book/data-applicability/)与[质量评分与概率](https://prism.tiangong.earth/zh/docs/book/data-quality-and-probability/)。
